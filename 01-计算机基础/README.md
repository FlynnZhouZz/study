## 建议顺序

1. **先建立全局图景**：[互联网是如何工作的](./01-计算机网络/01-互联网是如何工作的.md) → [Web 和 Web 标准](../02-前端核心/01-web开发/01-Web和Web标准.md)
2. **请求怎么走**：[HTTP 协议](./01-计算机网络/02-HTTP协议.md) → [TCP/IP 协议](./01-计算机网络/03-TCP-IP协议.md)
3. **页面怎么出来**：[浏览器是如何渲染页面的](./02-浏览器原理/01-浏览器是如何渲染页面的.md) → [-详细版](./02-浏览器原理/02-浏览器是如何渲染页面的-详细版.md)
4. **补充细节**：[面试之浏览器](./02-浏览器原理/03-面试之浏览器.md) 覆盖内核、进程模型、缓存等追问点
5. **补底层解释**：[进程与线程](./03-操作系统/01-进程与线程.md) → [内存管理与虚拟内存](./03-操作系统/02-内存管理与虚拟内存.md) → [IO 模型与多路复用](./03-操作系统/03-IO模型与多路复用.md)
6. **算法单独开线**：先 [数组与链表](./04-数据结构与算法/01-基础数据结构/01-数组与链表.md)，再按 [高级算法索引](./04-数据结构与算法/02-高级算法/README.md) 依次过排序、二分、回溯、DP、双指针

> 渲染流水线（DOM/CSSOM → Render Tree → Layout → Paint → Composite）是 P1 性能优化和 P3 打包优化的共同前提，务必读懂。
