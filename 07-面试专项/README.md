## 复盘流程

1. 面试后 24 小时内，在 `真实面试经历/` 新建 `YYYYMMDD 公司 面试.md`
2. 记录三段：**问了什么 / 我怎么答的 / 正确答法**
3. 把答不出的知识点链接到知识层原文，并直接在原文里补一节
4. 一周后回看，检查是否真的补上了
