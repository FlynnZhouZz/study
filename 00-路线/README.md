# 00-路线

整个知识库的**入口层**。学习从哪里开始、学到的新东西往哪补、新文档怎么写，答案都在这里。

| 文档 | 用途 | 什么时候看 |
|------|------|------------|
| [学习路线](./01-学习路线.md) | P0→P5 六阶段，每阶段含目标/核心文档/产出/自检 | 开始学之前，以及每次切换阶段时 |
| [命名与写作规范](./02-命名与写作规范.md) | 目录命名、文档模板、图片路径、提交规范 | 新建或重命名文档时 |
| [tools/gen-index.py](./tools/gen-index.py) | 重建各目录 README 索引 | 增删改文档后执行 |

## 与其他目录的关系

```text
00-路线   ──指引──▶  01 基础 → 02 核心 → 03 框架 → 04 工程化 → 05 后端
                          │                                   │
                          └────────── 06 实战项目 ◀───────────┘
                                          │
                                    07 面试专项（复盘，反哺知识层）
```

- `08-工具` 是辅助区，不进入学习主线。
- `99-手册` 是**办事清单**（申请账号、费用、平台后台操作，会随政策失效），`98-杂项` 与开发无关。这两个目录都不参与学习顺序，只在你真的要办某件事时才打开。
- 知识层的每一篇都可以被 `07-面试专项` 的题目反向引用；复盘发现的洞，补回知识层原文。

## 维护节奏

| 频率 | 动作 |
|------|------|
| 每次学习 | 自检问题答不上来的，直接补进对应文档，不留 TODO |
| 每次面试 | 24 小时内写复盘，发现的洞补回知识层原文 |
| 每月 | 翻一遍各目录 README 末尾的「已知缺口」，决定下个月补哪个 |
| 增删文档后 | 执行 `python3 00-路线/tools/gen-index.py` |
