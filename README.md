## 使用约定

1. **编号即顺序**：一级目录、二级目录、每篇文档都有 `NN-` 前缀。看编号就知道从哪开始，不用点进去猜。
2. **目录即分层**：`01-05` 是知识层（由底向上），`06` 是应用层，`07` 是复盘层，`08` 是辅助层。
   `99` 是**办事清单**（会失效的流程），`98` 是**杂项**（与开发无关）。后两者不参与学习主线。
3. **每个目录有索引**：新增文档后执行 `python3 00-路线/tools/gen-index.py` 重建索引。
4. **命名与写作规范**：见 [03-命名与写作规范](./00-路线/03-命名与写作规范.md)（含唯一例外：面试记录用日期代替编号）。
