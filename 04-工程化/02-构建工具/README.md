## 阅读顺序

先读 01 建立模型，再按你手上的项目选 02 或 03 深入。

判断标准不是"谁更快"，而是**你的瓶颈在哪**：

- 痛点是启动慢、热更新慢 → vite
- 痛点是产物体积、分包策略不可控 → webpack 的 `splitChunks` 仍然更成熟
- 库开发 → rollup / tsup
