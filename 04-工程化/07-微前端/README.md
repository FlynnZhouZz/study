# 微前端

> 把一个巨石应用拆成若干可独立开发、独立部署的子应用。适合「多团队共用一套页面」的组织问题，不适合「技术栈猎奇」。

| 方案 | 代表 | 说明 |
|------|------|------|
| 运行时沙箱 | [qiankun](./01-qiankun/README.md) | 基于 single-spa，JS 沙箱 + 样式隔离 |
| 模块联邦 | webpack 5 Module Federation | 构建期共享，无沙箱成本 |
| iframe | 无框架 | 隔离最彻底，通信与体验最差 |

现有内容：[qiankun 微前端实战](./01-qiankun/01-微前端实战.md)
