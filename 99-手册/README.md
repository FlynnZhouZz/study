## 01-04 上架资质与费用

从上架一个 App 要过哪些门、大概花多少钱开始看。费用随时会变，文内标注了整理日期。

| 编号 | 文档 | 用途 |
|------|------|------|
| 01 | [iOS 开发者账号申请及费用](./01-iOS开发者账号申请及费用.md) | 个人 688 元/年 vs 公司账号，以及各自的前置条件 |
| 02 | [邓白氏编码申请及费用](./02-邓白氏编码申请及费用.md) | 公司账号的硬门槛，免费但要走审核 |
| 03 | [App 推送通道申请及费用](./03-App推送通道申请及费用.md) | APNs、华为、小米、vivo、OPPO、Firebase 对比 |
| 04 | [App 开发收费项目清单](./04-App开发收费项目清单.md) | 从开发到上架运营的费用汇总 |

**建议顺序**：先看 04 建立成本预期 → 决定个人还是公司主体 → 走 01 → 公司主体再补 02 → 要推送就配 03。

| 编号 | 文档 | 用途 |

| 05 | [注册 AWS 账号](./05-注册AWS账号.md) | 使用 Polly 等 AWS 服务的前置 |
